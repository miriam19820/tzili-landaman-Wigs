בחרי את המסמך שלך

1

אילה — התחברות ודאשבורד

מערכת Login, JWT, ניהול צוות, דאשבורד מנהלת — טבלת סקירה ועומס עובדות.

 2

מרים — פאה חדשה

טופס הזמנה, 6 שלבי ייצור, תחנת עבודה, חתימה דיגיטלית, PDF ומייל.

 3

מרימי — תיקונים

קבלת תיקון, קטגוריות תיקון, זרימת משימות אוטומטית, חפיפה ובקרה.

 4

חני — בקרת איכות, חפיפה וסריקה

לוח QA, אישור ופסילה עם צילום, שירותי חפיפה, חיפוש היסטוריה לפי ברקוד.

איך להשתמש

  1. כל מפתחת פותחת את הדף שלה מהרשימה למעלה.
  2. קוראת את משפט הפתיחה בקול (30 שניות).
  3. מדגימה את המערכת לפי תסריט ההדגמה בדף.
  4. מסבירה קטע קוד אחד לפחות — מה נכנס, מה יוצא, ולמה.
  5. מוכנה לענות על שאלות המורה — התשובות מוכנות בסוף כל דף.
  6. לשמירה כ-PDF: לחצי Ctrl+P → "שמור כ-PDF".
