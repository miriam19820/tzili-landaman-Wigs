איך לשתף את מסמכי ההגשה עם החברות
====================================

שלב 1 — יצירת ה-PDFים (פעם אחת, מהמחשב שלך)
---------------------------------------------
1. פתחי טרמינל בתיקיית השרת:
   WigFlow-Project\server

2. הריצי:
   npm run generate-presentations

3. ה-PDFים ייווצרו בתיקייה:
   WigFlow-Project\docs\presentations\pdf\


שלב 2 — שליחה לכל חברה
-----------------------
שלחי לכל אחת את ה-PDF שלה (WhatsApp / Google Drive / מייל):

  אילה  →  ayala-login-dashboard.pdf
  מרים  →  miriam-new-wigs.pdf
  מרימי →  merimi-repairs.pdf
  חני   →  chani-qa-wash-scan.pdf


שלב 3 — אצל החברות
-------------------
כל אחת פותחת את ה-PDF שלה בכל מחשב או טלפון — בלי התקנות ובלי HTML.
אפשר גם להדפיס ישירות מה-PDF.


חלופה ידנית (בלי סקריפט)
-------------------------
1. פתחי את קובץ ה-HTML שלך בדפדפן (Chrome / Edge)
2. Ctrl+P → בחרי "Microsoft Print to PDF" או "שמור כ-PDF"
3. שמרי ושלחי
